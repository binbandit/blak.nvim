*blak.txt*  Blak Neovim distribution

BLAK                                                     *blak*

Blak is a native-first Neovim distribution built around a black-hole
identity and a low-bloat contract.

COMMANDS                                                 *blak-commands*

:Blak
    Open a short overview.

:BlakDoctor
    Run |:checkhealth| for Blak.

:BlakKeys
    Show effective Blak/user mappings, described native/plugin globals, and
    current-buffer shortcuts.

:BlakNews
    Open the Blak release notes.

:BlakDocs
    Open the Blak docs site at https://getblak.dev/start/why/.

:BlakConfig
    Open lua/blak/user.lua. If it does not exist, create it from
    lua/blak/user.example.lua first.

:BlakPick {kind}
    Run a picker. Kinds include: files, grep, buffers, recent, commands,
    keymaps, help, diagnostics, lsp_symbols, workspace_symbols.

:BlakExtras [list|enable|disable|sync] [id]
    Manage optional extras. With no args or "list", opens the extras UI.
    See |blak-extras|.

:BlackExtras [list|enable|disable|sync] [id]
    Alias for :BlakExtras.

:BlakUpdate
    Create a rollback snapshot and run |:Lazy update| within the current
    channel. Pending breaking migrations block this command.

:BlakUpgrade
    Create a rollback snapshot, apply pending upgrade migrations, then run an
    intentional bigger update.

:BlakRollback
    Restore the latest rollback snapshot and run |:Lazy restore|.

:BlakToolsInstall
    Install Mason tools required by enabled extras.

:BlakTreesitterInstall
    Install configured Treesitter parsers.

:BlakTerminal [cmd]
    Toggle the configured terminal provider. Native terminal splits are the
    default. With [cmd], run that command instead of the user's shell.

:BlakFormat
    Format the current buffer with Conform and the configured LSP fallback.

:BlakFormatToggle[!]
    Toggle format-on-save for the current buffer. Use bang for global.

:BlakSplash
    Preview the black-hole splash animation.

See |blak-keymaps| for the matching <Leader>l shortcuts.

CONFIGURATION                                            *blak-config*

Run >
  :BlakConfig
<
or copy >
  lua/blak/user.example.lua
< to >
  lua/blak/user.lua
< and return a table of overrides, or a function for full Lua control.

For example, to use SuperTab-style completion where Blak can delegate to the
completion engine: >
  return { completion = { super_tab = true } }
<
To make the active colorscheme use transparent editor backgrounds: >
  return { ui = { transparent = true } }
<
Theme-native setup options can be passed through ui.theme when the
colorscheme exposes a Lua setup() function: >
  return { ui = { colorscheme = "catppuccin-mocha", theme = { flavour = "mocha" } } }
<
Personal lazy.nvim specs can be added under plugins.specs: >
  return {
    plugins = {
      specs = {
        { "tpope/vim-sleuth", event = "BufReadPost" },
      },
    },
  }
<
Custom keymaps can use command strings or Lua functions, and mode accepts one
mode or a list: >
  return {
    keymaps = {
      {
        mode = { "n", "x" },
        key = "<leader>y",
        action = '"+y',
        description = "Yank to clipboard",
      },
      {
        key = "<leader>rn",
        action = function()
          vim.lsp.buf.rename()
        end,
        description = "Rename symbol",
      },
    },
  }
<
For full Lua control, return a function. Blak passes the config table it is
building before validation and extras apply: >
  return function(config)
    config.picker.provider = "snacks"
    table.insert(config.extras.enabled, "lang.typescript")
  end
<
Use hooks.after for Lua that should run after Blak setup and after successful
user.lua reloads.

Config functions can remove defaults with nil, for example
config.lsp.servers.lua_ls = nil. Enabled extras apply afterward; disable the
corresponding extra as well when removing its tooling.

Saving lua/blak/user.lua while Blak is running reloads the merged config and
refreshes the current session. Run :BlakExtras sync or :Lazy sync after adding
or removing plugin-backed extras; restart to unload runtime hooks that already
ran.

Syntax and validation errors leave the accepted config active. Fix the file
and save again; external editors replacing user.lua are supported too. Keymap
modes use Neovim short names (n, i, x, etc.); invalid names fail validation
before active keymaps are refreshed.

A failing or unknown nvim-lint entry warns independently, so other configured
linters can still run.

Supported stable Neovim releases (0.12+) are the baseline. Nightly is a
compatibility target, not a requirement for everyday editing.

UPDATE SCOPE

:BlakUpdate and :BlakUpgrade update plugins, not the Blak Git checkout. Review
NEWS.md and local changes before running git pull --ff-only in the config
checkout. Restart and run :BlakUpgrade for pending migrations. Snapshots do not
include the distribution revision, Mason tools, or Treesitter parsers. Lazy
restore may need network access for missing commits or build artifacts.

Only language servers in lsp.servers are automatically enabled. Disabling an
extra and restarting stops its LSP wiring, but installed Mason tools remain.
mason.automatic_install=false disables automatic tool and server installs;
:BlakToolsInstall explicitly requests both.

lang.typescript uses the native TypeScript 7 server, tsc. Run :BlakToolsInstall,
wait for completion, then restart after updating. Explicit lsp.servers.ts_ls
entries remain configured; remove them to use only the native server. To retain
ts_ls, replace lang.typescript with lang.typescript-legacy and restart.

lang.typescript-legacy uses a compatible workspace SDK, then Mason's copy.
Explicit lsp.servers.ts_ls.init_options.tsserver.path and before_init overrides
are preserved. ts_ls requires tsserver.js, which TypeScript 7 removed. If it
reports "Could not find a valid TypeScript installation", run :BlakToolsInstall,
wait for completion, then restart. Tool installation repairs Mason copies
missing tsserver.js; automatic repairs respect mason.automatic_install=false.
:BlakDoctor checks Mason's TypeScript fallback when ts_ls is configured.

:BlakKeys lists effective Blak mappings, described global/native mappings, and
current-buffer shortcuts. Buffer-local overrides take precedence. Inspect
global mappings without descriptions with :BlakPick keymaps or :map.

<Space>cf runs :BlakFormat with or without an attached LSP. :2,5BlakFormat and
:'<,'>BlakFormat format complete selected lines. Per-filetype Conform options
override global formatting defaults. An empty formatter list still allows LSP
fallback; { lsp_format = "never" } disables both for that filetype.

In terminal input mode, <C-\><C-n> returns to Normal mode; <Space>tt hides the
terminal. Reopening an exited shell creates a fresh one and retains its output.

lang.typescript-tsgo is a compatibility alias for lang.typescript. It retains
its saved ID. Legacy tsgo settings are carried forward; explicit tsc settings
win. Run :BlakToolsInstall and restart after updating. Basic Python uses Ruff
LSP diagnostics without also invoking nvim-lint. Python Pro supersedes basic
Python; native TypeScript supersedes legacy TypeScript. They replace only
unchanged extra-contributed defaults, regardless of activation order. Explicit
user settings remain in effect.

Native gzip, tar, zip, and Tutor plugins remain enabled. Only the netrw directory
handler is disabled for Blak's explorer. To disable individual native helpers,
set the corresponding loaded_* flags in hooks.before (see their Neovim help).

Stable Neovim 0.12 also bundles optional undo-tree and directory-diff tools:
  :packadd nvim.undotree | Undotree
  :packadd nvim.difftool
  :DiffTool path/to/old path/to/new
Use :lsp restart to restart clients attached to the current buffer. See
https://getblak.dev/guide/native-neovim/ for recipes and native completion.

Reload preserves Conform and Blink options from plugins.specs. Removed formatter
filetypes and LSP settings no longer linger in the rebuilt configuration;
restart Neovim to apply LSP settings to clients that are already running.
